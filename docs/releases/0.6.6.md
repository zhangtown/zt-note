飞牛 NAS 上的自托管思源笔记（笔记存在你自己的 NAS 上，`.sy` 原生格式，可随时导出回思源）。

这一版只做一件事：**把图标重画了一遍**，功能与 0.6.5 完全一致，不必为了功能升级。

## 新图标

旧图标是深蓝渐变方块里放一页纸，能用但偏"早期扁平风"，也跟飞牛官方应用的观感不在一个频道上。
新版按飞牛官方那套语言重画：**浅底 + 通透玻璃感 + 只在主体上给一处高饱和**——

- 浅蓝渐变圆角底（不是纯白，白顶栏上也看得见轮廓），带柔和内辉光与极淡描边
- 磨砂玻璃文档：亮蓝渐变 + 顶部高光 + 左侧镜面反光 + 三条深浅不一的白文字线
- 顶部一朵白云（白→浅蓝渐变），点"云栖"的题
- 文档下方一层高斯模糊柔影，让主体从底板上"浮"起来

同一套几何用在四个地方，互相不再打架：

| 位置 | 来源 |
|---|---|
| 应用中心 / 桌面图标 | `ICON.PNG`(64)、`ICON_256.PNG`(256) |
| 应用内嵌页面图标 | `app/ui/images/icon_{64,256}.png` |
| 浏览器标签页图标 | `icon.png`（打包时由 `tools/mkicon` 生成） |
| 应用内首页、PIN 门、启动失败页 | `ui/src/logo.ts` 的内联 SVG（同一份几何的矢量版） |

## 可以自己改

图标不再是手工产物：`tools/mkicon` 用 Go 标准库逐像素渲染（符号距离场 + 3 倍超采样），
改设计只改 `tools/mkicon/main.go` 再跑一次：

```bash
go run ./tools/mkicon     # 一次写出上面四份 PNG（两个 64/256 尺寸）
bash build.sh fpk         # 打包时也会自动重生成一遍
```

## 升级注意

- `appcenter-cli install-fpk` 对**已安装**的同名应用是空操作（版本号更高也不换文件）；升级请用
  `install-local`，`deploy/fnos-app/install.sh` 已经封装好了
- 这版不动数据、不动接口、不动存储格式，升级只是换图标与静态产物
- 应用层只有一道 6 位 PIN，磁盘上的 `.sy` 仍是明文，**不要把它当加密用**
